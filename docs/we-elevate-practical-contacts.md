## ⚠️ PERMIT NOTES

**For your project, you'll likely need to check:**

1. **Zoning** — Is the property in city limits or unincorporated Milam County?
2. **Building Permits** — For cabin construction, common building
3. **Septic / Well** — If not on city water/sewer
4. **Agricultural Exemption** — If using land for farming (lowers property taxes)
5. **Fire/Health Inspections** — For residential facility

**💡 Pro Tip:** Ask the realtor or county clerk about "agricultural exemption" — many rural properties already have it, which keeps taxes low.
