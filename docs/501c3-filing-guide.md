# We Elevate — 501(c)(3) Filing Guide

*How to get tax-exempt status (so you can apply for grants)*

---

## The Two Paths

### Option A: File Directly with IRS (Slower but free)
1. File Texas LLC with SOS ($300)
2. Get EIN from IRS (free)
3. File IRS Form 1023 or 1023-EZ (fee: $275-$600)
4. Wait 3-12 months for determination

### Option B: Use a Fiscal Sponsor (Faster)
Work under another nonprofit's 501(c)(3) until yours is approved. They handle the money, you run the program.

---

## Step-by-Step: File Your Own

### 1. Form Texas LLC
- **Where:** sos.state.tx.us/corp (SOSDirect)
- **Cost:** ~$300
- **Turnaround:** 3-5 days (1-2 days expedited)
- **Name ideas:** "We Elevate" or "Wanderlust & Co." (check availability)

### 2. Get EIN
- **Where:** irs.gov/ein
- **Cost:** Free
- **Time:** 5 minutes

### 3. File for 501(c)(3) Status

**Option A: Form 1023-EZ** (Simplified — most small nonprofits use this)
- **Fee:** $275
- **Turnaround:** ~3-6 months
- **Best for:** Organizations with <$50K annual revenue, straightforward mission
- **Where:** irs.gov/gos/form1023

**Option B: Form 1023** (Full application)
- **Fee:** $600
- **Turnaround:** 6-12 months
- **Best for:** Larger operations, complex programs

### What You'll Need
- [ ] Articles of Organization (from Texas LLC filing)
- [ ] EIN confirmation
- [ ] Bylaws
- [ ] Mission statement
- [ ] Organizational structure (who does what)
- [ ] Budget (startup + first year)
- [ ] Description of programs
- [ ] List of directors/officers

## Pro Tips

1. **Apply for TSAHC before 501(c)(3) is approved** — they accept "in formation" applications
2. **Start gathering docs now** — bylaws, budget, mission statement
3. **Consider fiscal sponsor** if you need to move faster (another nonprofit to hold funds)
4. **Use 1023-EZ** — it's faster, cheaper, and sufficient for your size
